# 翻译风格说明

- 采用准确、简洁的学术中文，保留原文论证顺序、章节编号和实验条件。
- DROPO、DROID、BayesSim、PPO、SAC、CMA-ES 等专名和缩写保留；首次出现时补充中文解释。
- 保留变量、矩阵、概率分布、公式编号、单位与数值，不改写为近似结论。
- 统一将 domain randomization 译为“域随机化”，dynamics 译为“动力学”，sim-to-real transfer 译为“仿真到现实迁移”。
- 图注作为正文文本翻译，图像中不烧录中文；引用编号和参考文献书目保持英文。
- 附录 B–D 的补充敏感性结果和混合高斯联合图做结构化译读摘要；完整图表与书目以随附原文 PDF 为准。
